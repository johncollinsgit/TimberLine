# Campus search and assistant layout reconciliation

This is a source change. Normal exact-head CI, review, protected deployment and
actual-page acceptance remain separate. It does not publish a new private edition,
change an account, connect a provider or initialize a budget.

| Surface | Search and assistant authority | Persistence and acceptance boundary |
| --- | --- | --- |
| Public `/platform/demos/lees-mcrae` | Header search and guided assistant use only the current fictional projection. Opening a result refreshes that projection and checks the exact persona, kind and ID. No native/private API, model, microphone or provider connection. | Existing browser session records and per-persona drafts remain. Real selected JPEG/PNG/PDF bytes remain in tab memory; metadata is not a shared upload or a clean scan. |
| Signed-in `/enterprise-campus` | Existing authenticated CampusSearch and Ask/voice services retain current actor, tenant, department and feature checks. Presentation does not grant access. | Existing server records, receipts and private files retain their own authorization and quarantine. Browser fixtures do not prove physical speech or hosted account acceptance. |
| Current-source private shared renderer | Its own current authorized graph and admitted adapters; never a fallback to native or public records. Existing publication/feature gates remain. | Server comments/files require an admitted current edition and their separate policies. Source/CI acceptance cannot activate them for a recipient. |
| Preserved private v5 | Original signed legacy renderer and original review binding. | No automatic upgrade, reseed, link replacement, expiration extension or feedback migration. Compatibility proves preservation, not new shared-workspace capabilities. |

The public Campus assistant is one retained modeless panel beside the guided
walkthrough control. Ordinary navigation and Close retain the same draft DOM;
step changes retain the bounded persona draft. Escape restores launcher focus.
Perspective changes immediately retire former search and assistant handlers,
including while the asynchronous new projection is loading. Explicit creation
still leads through clarification and summary to the existing request form;
only its explicit Submit dispatches the retained local intent. Global search is
record lookup, never an implicit creation command. Result selection is explicit.

The public shell's bounded browser-history state contains only view, project,
layout and panel visibility. Back restores current permitted context rather than
replaying an action. Search and assistant controls do not replace request
composers, selected files or uncertain write identities. Current dialogs close
through their existing draft-retention lifecycle. Tour and assistant overlays
are mutually exclusive; both launchers remain reachable above the safe area.

Map labels show a known building name only for the existing exact ID plus
explicit saved location association. Job IDs remain separate work identifiers.
J05 and ambiguous/custom locations say **Building not specified**. Moving a
fictional pin does not establish a building association, GPS fix or campus fact.
Records, positions, deletions, ownership and the existing fixture counts are not
rewritten by this presentation change.

Reuse the existing comments, attachment and assignment-history implementations.
Acceptance must keep all prior assertions and add a real different-person
assignment, exactly one new history event, linked owner parity and saved prefill.
Same-person edits must still avoid fabricated reassignment events. Keep initial
and later JPEG/PNG/PDF checks, permission denials, draft/file identity, explicit
submission and reload checks. Retain every full guided-tour scene and both
browser engines at desktop and phone viewports. A viewport test does not certify
physical mobile Safari, microphone use or actual provider operation.

Financial presentation is documented in
`proposal-financial-usage-example.md`. Its example and collapsed adjustments do
not change the calculator, selected services, rates, terms or saved comparisons.

A current private edition requires the existing actual-owner preservation,
capture/reconciliation, preparation, separate publication and initialization
procedure in `proposal-reviewer-workspace-preparation.md` and
`proposal-reviewer-workspace-initialization.md`. Preserve old links, selected
reviewer names, comments, graph IDs/deletions and canonical plans. A clean source
fixture is not recovery of current work. Missing capture/runtime/cleanup
authority is a concrete private-edition blocker, independent of ordinary UI
source delivery. No API key, provider/capture flag, scanner, grant or budget is
configured by this change.
