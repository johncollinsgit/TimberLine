# Everbranch Showcase presentation

Implementation branch: `codex/everbranch-showcase-polish`, based on production release
`1a777845ca3c7ffe6ccceb73804ead0ee4a97c1a` (2026-10-14).

The approved reference is the current Everbranch Showcase workspace, job, gallery,
and AI screenshots. The web workspace adopts its sage paper, ivory cards, forest
ink, Avenir typography, 12–18px corners, solid readable controls, and quiet borders.
The workspace uses the full canvas beside the existing sidebar. Native selects
keep platform keyboard/picker behavior with a consistent field and chevron.

`resources/css/everbranch-workspace.css` is opt-in through the shared server-rendered
`data-eb-workspace` marker. The configured flagship console, Shopify embedded
shells, checkout, agreement/payment surfaces, and tenant public websites
retain their presentation contracts. Business logos and all access checks remain
server owned. Public Everbranch auth copy no longer borrows flagship branding;
this changes presentation only, preserving tenant intent and membership checks.

Phone/tablet Jobs and Customers use cards from their existing paginated API rows.
A job card opens the existing full job route in one tap; the contextual header
retains business identity and a real parent/back destination. Desktop inline grid
editing remains available. The canvas grids use the same palette and larger text.
Real uploaded job photos can become a cover when the existing Documents and
owner-file gates permit viewing, and still open the authorized original;
no sample job photos or simulated AI enter production. Task progress uses saved
server statuses. Field dashboards prioritize work and place storefront statistics
inside a collapsible, deliberate entry point.

The real customer message surface remains the existing consent-aware send wizard
and delivery log. It is styled rather than replaced with fictional conversations.
A complete native-style web inbox/thread composition is a separate capability gap.

Validation uses fresh synthetic SQLite databases, local mail output, blocked server
outbound networking, and no running queue worker. Passwords, reset URLs, session
cookies, real customers, production data, and provider credentials must not appear
in screenshots or review attachments. Device evidence is browser emulation; camera,
soft keyboard, native app, offline, and physical-device checks remain separate.

Before publication, retain the GitHub test/build gate and protected Forge release
process. Publication requires those gates and exact-release readiness verification. The audit's access and billing
findings are independent of this presentation change and are not certified fixed.

## Owner controls and landlord console

The landlord console shares the accessible sage/ivory controls and full-width
canvas. Five primary groups replace the earlier flat navigation: Home, Clients,
Money, Support, and Platform. Detailed client setup guidance is collapsible,
while existing actions, confirmations, host guards, and permission checks remain.
Receipt metrics are described as recorded receipts rather than certified revenue;
the cost coverage number is explicitly an estimate from the incomplete ledger.

Workspace presentation is stored in existing access-profile metadata. The owner
can select General, Field, Care, Studio, Nonprofit, or Retail and edit introductory
copy from the client Settings page. Only an active landlord operator matching
`EVERBRANCH_WORKSPACE_TEMPLATE_OWNER_EMAIL` and the existing landlord commercial
gate can write. Blank configuration disables editing. Configure that email for
the requested owner account through the normal release process; the local
synthetic owner is not a production account. Saves preserve plan, operating mode,
other metadata, and entitlements, and append before/after audit evidence. Repeat
identical submissions do not create another audit event. No migration is needed.

Care and Nonprofit editorial images derive from the supplied Showcase assets;
their generation provenance is recorded in its `docs/branding.md` and
`docs/image-prompts.json`. Other collection images are existing Everbranch public
photography. These illustrate the brand; they are not client work or endorsements.

Landlord screenshot coverage contains synthetic records only. External charge,
message delivery, integration provisioning, destructive client operations, and
physical devices remain outside visual verification.
