not proof of a particular live demo configuration. Do not copy those mappings,

## First milestone and acceptance

1. Enlarge selected project/request detail. Add project discussion using a native
   scoped task and existing comment/file services. Bottom composer retains text
   and stable retry IDs across in-page navigation. Uploads resume by content
   checksum and client key, validate type/size and remain private/quarantined
   until the existing scanner declares clean. Photos, PDFs and text are the
   supported types; no arbitrary executable file acceptance.
2. Add a department-scoped contractor register and planned date blocks linked
   to authorized work. Serialize inclusive date overlaps per contractor/area.
   Store integer minor-unit estimates/recorded costs separately, visible only to
   current organization owner/admin. No contractor accounts or purchasing.
3. Add chat-based Ask Everbranch. Each turn rebuilds bounded current authorized
   evidence, provides server-owned record links and freshness/coverage limits,
   and identifies the signed-in user and role. Record text is untrusted. The
   useful default is explicit record-backed answers; model interpretation is
   unavailable until a separately reviewed provider/usage integration is ready.
   Reuse the existing transport seam in fake-provider tests; no retail config
   or credentials are imported and no live model call is enabled.
4. Stage own-mailbox email drafts: exact sender/recipient/subject/body preview,
   immutable digest, expiry, explicit confirmation, current user/department/
   source reauthorization and durable idempotent dispatch/uncertain outcomes.
   Default gateway has no connected mailboxes and cannot send. Fake adapters
   exercise the full contract; real connection/transport acceptance is later.

Acceptance includes wrong tenant/department/user, revoked role and stale version
negatives; prompt injection and forged citation rejection; duplicate/interrupted
notes/uploads; unsupported/mismatched bytes and unavailable scanners; expired/
modified/cross-user email approvals; zero grants, billing or real sends. Browser
checks cover desktop, phone and tablet portrait/landscape, selected detail and
unsent text retention, touch targets and horizontal overflow. Viewport simulation
does not establish physical iPad camera, picker or keyboard acceptance.
