# Lees-McRae source-backed locations

`lees-mcrae-locations.json` preserves the 68 numbered entries on page 2 of the
official 2026 campus parking map, supplied and visually checked by the owner's
research worker. `official-campus-plan.png` is a raster rendering of page 1 of
that same public PDF, downloaded October 22, 2026:

https://www.lmc.edu/campus-life/campus-safety/campus-operations/files/campus-parking-map.pdf

The map's printed numbers are source evidence. No coordinate, ownership,
department, inventory or operational activity is inferred from its drawing.
The image is a reference plan, not a GPS layer. It creates no college records.
Locations are imported only into explicitly marked local/testing fixtures or
entered individually by an already authorized operator. Unknown coordinates
remain null; do not add invented map pins.
