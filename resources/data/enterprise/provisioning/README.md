# Reusable client manifests

lees-mcrae-demo.json is a proposed configuration, not an installed tenant or
institutional identity claim. Its fixed UUIDs name the requested single demo
silo; another client/environment must use its own reviewed IDs and runtime.

The 68 source references preserve the approved local official-map legend.
The shared-directory mapping controls software record visibility and makes no
physical ownership, responsible-department or location-placement claim. No
employees, accounts, memberships, entitlements, projects or workflow runs are
created by this file. Operations is a proposed pilot department; the shared
catalog is common configuration rather than an extra billing activation.

The independently prepared runtime, database, key, storage, routing and initial
owner access still require the explicit operator approvals in the hosting
proposal. Preview the exact manifest with enterprise:client plan, then review
its target and hash before any authorized apply. No connection, send, paid call
or recovery operation is activated. Backup/recovery remains plan-first.
