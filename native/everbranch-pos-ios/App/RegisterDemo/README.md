Modern Forestry Pay catalog shell

Derived from the owner's Everbranch Pay style demo saved October 24, 2026.
Retains its forest artwork, public product photographs, variant selection and
three approved bundle offers. Product facts are a snapshot, not live inventory.

Fictional events, staff switching, sales history, simulated payments, fake
receipts and sample tax rates were removed. Basket review shows a subtotal and
requires verified tax/stock/prices at a connected register. No checkout from
this local page creates a sale or sends a basket to the payment backend.

The only native message is {action: "setup"}. Its handler accepts the bundled
main-frame file only and opens the existing native setup/recovery UI. External
navigation and network API requests from the page are blocked. Credentials,
device authorizations, recovery records and Square payment UI remain native.

Images are cached copies of the original public catalog photos for browsing
without a network connection. The app icon is the owner's existing Modern
Forestry icon, copied without modification. New device builds and UI checks do
not establish merchant authorization, deployment, stock review or payment
acceptance. Follow the existing POS runbooks before collecting money.
